## What this page is for

**1. Plan runs** (this page) shows which products we should build and send to Amazon next.

**Who uses it:** Becca and Adam decide. Chad can read it to see what is coming.

## The list

The page is called **1. Plan runs** in the menu. It is the first page. The list is in groups: **PS**, **Danesi** and **Clear Conscience** come first, then the other groups. Find your products inside the group.

Each row shows how many we sold, what is at Amazon, and **Recommended Send**. The column **Why** explains the number in one line.

The columns you use sit side by side: **Recommended Send**, **Stock Alert**, **Send Need**, **Override**, **Add To Run** and **Rush**.

- **1 – Recommended Send:** how many the system suggests we build and send. It plans enough stock at Amazon for **45 days**, plus the days Amazon needs to receive a shipment (about **12 days** now; RemBase updates this every day). It also takes away what open runs will already make. The line in **Why** shows this as **open runs**. The list is sorted by this number.
- **2 – Stock Alert:** empty is fine. If it says **NEED MORE: X short**, the row is red. We need more than we can send (X units short). Tell Adam.
- **3 – Send Need:** how many we need to send. You cannot change it.
- **4 – Override:** Becca types her own number here to replace the suggestion.
- **5 – Add To Run:** tick to put this product in the next runs.
  When you tick **Add To Run** and **Override** is empty, RemBase fills it with **Recommended Send**. Change the number if you want a different one. A number you typed is never changed.
- **Rush:** tick it here if the run is urgent. Rush runs are at the top of the run lists.
- **Max Available to Build:** (scroll right) how many we **could** build with the parts we have now.
- **Days Of Cover FBA:** how many days the stock at Amazon will last. Blank, with 0 at Amazon, means the part is no longer in Amazon's report. See [Inventory](inventory.html).
- **Warehouse On Hand Qty:** all units of this product in our warehouse.
- **Warehouse Ready Qty:** finished units. They can ship now.
- **Warehouse Needs Prep Qty:** raw units. They need prep (label, sticker) before they can ship. Plan a prep run first.
  Example: a product shows **Ready 0** and **Needs prep 120**. Nothing can ship yet. Make a prep run for it first.

::: note
**Max Available to Build is not stock.** For a pack, it is how many packs the parts can make. For a single part that goes into packs, it is what is left after the packs take their share.
:::

The numbers update every hour. During the update some rows can show different times. Wait a few minutes and look again.

## Commit the runs (Becca only)

Commit is on the **1. Plan runs** page itself.

1. Tick **Add To Run** on each product (type **Override** first if you want your own number).
2. Check that **only** the products you want are ticked. The ticks are shared.
3. Press **Commit staged runs** (top of the page). RemBase asks **Are you sure?** Press **Yes** **once**.
4. Read the result line. **DONE: … run(s) made** lists the new runs. The ticks and numbers are cleared.

There is no separate Commit page in the menu now.

Do not press **Commit staged runs** unless you are Becca.

## Common mistakes

- **Reading Max Available to Build as stock.** It is not stock.
- **Ticking Add To Run to "try it".** The ticks are shared. Becca's next commit would use them.
- **Thinking a number is wrong during the hourly update.** Wait a few minutes.
