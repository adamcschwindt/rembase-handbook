---
title: Glossary
subtitle: Words used in RemBase
slug: glossary
order: 15
---

| Word | Meaning |
|---|---|
| **Bin** | A place on a shelf where stock is kept. Each bin has a name, like 01-A3. |
| **Lot** | One group of the same part with the same expiration date in the same bin. |
| **Expiration date** | The "use by" date on the box. |
| **FEFO** | "First expired, first out". Use the stock that expires first. RemBase picks lots this way. |
| **Ledger** | The list of every stock move: receipts, runs, counts, shipments. |
| **On hand** | How many we have now. |
| **PO (purchase order)** | An order we send to a vendor. |
| **PO line** | One part on a PO, with its quantity and price. |
| **Vendor** | The company we buy from. |
| **Receipt** | The record that stock arrived. |
| **Outstanding** | Ordered but not arrived yet. |
| **Backorder** | A PO line the vendor has not sent yet. |
| **Units** | Single items. |
| **Case** | A full box from the vendor with many units. |
| **Component** | A part used to build something else. |
| **Kit / pack** | A product built from components, like a 2-pack. |
| **BOM (recipe)** | The list of components needed for one kit or pack. |
| **Production run** | One job of building kits or packs. |
| **Carton** | A box we pack for Amazon. |
| **Pallet** | A wooden base that holds many cartons for a truck. |
| **FBA** | "Fulfilled by Amazon". Amazon stores and ships our products. |
| **FBA shipment** | One group of cartons we send to an Amazon warehouse. |
| **FBA ID** | Amazon's number for a shipment. It is on every box label. |
| **Plan** | The first step with Amazon. It lists what we want to send. |
| **Placement** | Amazon's choice of which warehouse gets our boxes. It has a fee. |
| **Freight** | Shipping by truck. |
| **Carrier** | The truck company. |
| **BOL (Bill of Lading)** | The paper the truck driver signs when they take the pallets. |
| **Label** | The sticker on a box or pallet that Amazon scans. |
| **Inbound** | Stock on the way to Amazon. |
| **FNSKU** | Amazon's barcode number for one product. |
| **Cycle count** | Counting one bin to check it matches RemBase. |
| **Variance** | The difference between what RemBase says and what you counted. |
| **Flag** | A problem the system found and wants someone to look at. |
| **TEST item** | A fake part, bin or PO used only for practice. Its name starts with TEST. |
